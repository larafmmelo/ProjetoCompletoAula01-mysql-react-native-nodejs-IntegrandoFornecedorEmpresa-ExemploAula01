# Fornecedor Node + MySQL + React Native

Repositório desenvolvido para integrar os conteúdos das atividades de Banco de Dados, Node.js, MySQL e React Native.

O projeto reúne:

* Cadastro e consultas de Fornecedores;
* Banco de dados de Livraria;
* Exercícios de consultas com Voo;
* Exercícios de consultas com Hotel;
* Backend em Node.js + Express;
* Integração com MySQL;
* Configuração para utilização no GitHub Codespaces.

## Tecnologias

* Node.js
* Express
* MySQL
* React Native
* GitHub Codespaces

## Estrutura

Os arquivos SQL estão organizados na pasta `database`, os exercícios em `exercicios` e o backend na pasta `backend`.
